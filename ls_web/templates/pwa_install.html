Instalēt LocalSunoDb

Chrome Web App / uzdevumjosla

Šī vienreizējā darbība piešķir LocalSunoDb savu Chrome aplikācijas identitāti un LS ikonu Windows uzdevumjoslā.

Gaidām, kamēr Chrome sagatavo instalēšanu.

Pēc veiksmīgas instalēšanas LS saīsnes tiks atjaunotas automātiski. Šo Chrome cilni pēc tam var aizvērt.
